# cpp_remote_control

基于 **C++20、Win32 API 和 Winsock2** 开发的 Windows 远程桌面控制实验项目，采用客户端（控制端）—服务端（被控端）架构。目前已具备远程屏幕画面传输、窗口显示和部分键鼠交互功能，主要用于学习 Socket 通信、Windows 图形接口与多线程程序设计。

> **项目状态：开发中。** 已实现主要功能的代码框架，尚未进行完整的兼容性、安全性和稳定性验证，不建议直接用于生产环境。

## 设计架构

项目使用两条独立的 TCP 连接：

- **控制通道（9999）**：客户端向服务端发送鼠标和键盘操作指令，服务端调用 Windows API 执行相应操作。
- **屏幕通道（10000）**：客户端请求画面；服务端截取桌面、编码为 PNG 并传回；客户端解码后在 Win32 窗口中显示。

通信数据通过自定义数据包传输，由包标识、命令类型、数据长度和消息体组成。客户端采用界面线程与屏幕接收线程协作，服务端分别处理控制和屏幕请求。

## 运行方式

1. 在 Windows 下使用支持该解决方案及 **MSVC v145** 工具集的 Visual Studio 打开 `远程控制软件.slnx`，编译两个工程。
2. 先在被控电脑运行 **RemoteControl**，再在控制电脑运行 **client**。
3. 在 `client/client.cpp` 的 `remote_ip` 中配置被控电脑的可达 IP 地址（当前代码使用 Tailscale 网络地址）。确保双方网络可达且 **9999、10000** 端口允许连接。
4. 连接成功后，控制端窗口请求并显示远程画面，可通过窗口发送部分鼠标、键盘操作。
