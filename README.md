# cpp_remote_control：C++ 远程控制项目

这是一个基于 **C++20、Windows API 和 Winsock2** 的远程控制学习项目，采用客户端—服务端（Client–Server）架构。目前主要用于实践 TCP Socket 通信、应用层数据包封装、屏幕截图和远程指令处理的基本流程。

**项目仍处于开发阶段，尚不能实现完整的远程桌面控制。**

## 项目架构

- **服务端（RemoteControl）**：监听客户端连接，接收和解析数据包，向客户端返回测试消息，并包含本地屏幕截图代码。
- **客户端（client）**：主动连接服务端，发送测试数据包并显示服务器的响应。
- **通信协议**：使用自定义包头（标识、命令号、数据长度）和消息体组织 TCP 数据。


注意：服务端工程实际引用 `client/RemoteControl.cpp`，而非 `远程控制软件/` 文件夹中的同名源码。

## 环境与运行

**环境：** Windows 10/11、Visual Studio（支持 `.slnx` 解决方案和 MSVC v145 工具集）、Windows SDK。项目配置使用 C++20，并依赖系统的 Winsock2、Windows API、ATL/GDI+ 相关组件。

1. 克隆仓库：`git clone https://github.com/zyfmessi/cpp_remote_control.git`
2. 用 Visual Studio 打开 `远程控制软件.slnx`，选择 `x64 / Debug` 配置并构建两个项目。
3. 先启动 **RemoteControl**，按提示按 Enter 后开始监听；再启动 **client**。
4. 默认连接地址为 `127.0.0.1:9999`，客户端会发送测试消息，服务端将其回传。启动服务端时会尝试在**程序当前工作目录**生成 `test.png`。

## 当前限制与注意事项

- 目前以本机回环地址的通信测试为主，**截图不会通过网络发送给客户端**。
- 数据包边界处理和异常校验仍需完善；代码也没有实现认证和加密。
- 仅建议在本人拥有或明确获准管理的设备、隔离测试环境中使用，不要直接暴露服务端端口到公网。
